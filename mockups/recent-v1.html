The Recent list, three ways

The row you have is the generic iOS list: a small ring, a title, a run-on subtitle, a chevron. It is the most app-shaped thing left on Home. Each option below is lifted from somewhere that solved the same problem, which is how do you show a thing somebody DID so it feels like an achievement rather than a log line.

A · Strava's activity card. A header that names the thing, then a rule, then the numbers as three labelled columns. Strava does exactly this with Distance, Pace, Time, and the reason it works is that every card has the same three columns in the same places, so you compare two sessions by looking down rather than by reading. A missing breath is a dash, not a gap.

B · Hevy's workout row. The same facts as chips instead of columns, which fits the bubbly language better and handles a missing signal by simply not being there. The cost is that nothing lines up between two cards, so it reads as a label cloud rather than a record. Prettier per card, worse as a list.

C · Letterboxd's diary, with Otto standing in for the poster. Every entry gets a picture. When Friends is on that panel is the selfie you took; when it is off it is Otto in a pose picked by how the sit went. Charming, and it is a claim the data cannot always keep: three identical Ottos down the screen would be worse than no picture at all.

What I would ship

A, and it is not close. The list's job is comparison: you look at it to find out whether this week was better than last. Aligned columns do that and a chip cloud does not, which is the same argument as the week strip. B's chips are prettier in isolation and I would use that shape somewhere a single session stands alone. C is the one to revisit when Friends ships and the picture is a real selfie rather than a mascot wearing the same face three times.
